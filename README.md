# LogSense

A full-stack web-based Log Monitoring and Security Analysis Dashboard.

## 🚀 Features

- Real-time log dashboard
- Log statistics and analytics
- Activity chart
- Security severity overview
- Top Source IP analysis
- Search and filter logs
- Create new logs
- View detailed log information
- Delete logs
- Security alerts
- SQL Injection detection
- XSS detection
- Suspicious endpoint detection

## 🛠️ Technologies Used

### Frontend
- React.js
- JavaScript
- CSS
- Axios

### Backend
- Node.js
- Express.js
- REST API

### Database
- MySQL
